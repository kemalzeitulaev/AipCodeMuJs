209:

функция сразу возвращает значение num, 
то есть 3. После выполнения return функция заканчивает работу, 
поэтому вычисление квадрата и второй return никогда не выполняются.

func(10) — число больше нуля, поэтому выполняется return num ** 2: результат 100.
func(-5) — число меньше нуля, поэтому выполняется return Math.abs(num): результат 5.
Math.abs() возвращает абсолютное значение числа, то есть убирает знак минус.

func(10) — условие num <= 0 ложно, поэтому блок if пропускается
и выполняется return num ** 2. Результат — 100.
func(-5) — условие истинно, 
поэтому функция возвращает 5 и завершает работу. 
Последний return уже не выполняется.

215:
Имя sum не отражает действие полностью: функция считает среднее арифметическое, а не сумму.
Лучше использовать имя calcAverage.

function calcAverage(arr4) {
    let sum2 = 0;
    for (let elem3 of arr4) {
        sum2 += elem3;
    }
    return sum2 / arr4.length;
}
console.log(calcAverage([2, 4, 6]));
